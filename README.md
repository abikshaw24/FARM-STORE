# 🌿 Farm Organic Store

A full-stack **Farm Organic Store** web application built using **HTML, CSS, JavaScript, Express.js, and MySQL**. The project provides a modern shopping experience with an automatic hero image slider, product catalog, shopping cart functionality, customer testimonials, FAQ section, blog section, store location, and a contact form with JavaScript validation. The frontend communicates with an **Express.js backend**, and customer details are stored securely in a **MySQL database**.
